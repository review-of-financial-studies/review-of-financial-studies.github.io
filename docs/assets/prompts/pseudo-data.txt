- Keep the pseudo-data as small as possible while still allowing all code to run, e.g., by reducing the number of entities rather than columns or the sample period.
- Make sure identifiers are consistent across files so that all merges work.
- Set seeds for all random draws.

Include the script that generates the pseudo-data in the replication folder. Finally, verify that the full code runs without errors on the pseudo-data from the main entry point and produces all tables and figures listed in the README.
